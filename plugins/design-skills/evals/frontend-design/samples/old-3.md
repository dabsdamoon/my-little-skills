A. Build brief: FIELD SIGNAL

Make the HUD feel like a compact rescue instrument: pale enamel panels, near-black figures, vermilion danger marks, precise tick marks. The battlefield remains the dominant surface. No introductory copy or decorative heading. Barlow Condensed numerals give timers and HP a distinctive instrument-panel character; Atkinson Hyperlegible handles names and labels.

Use an asymmetric perimeter arrangement, not a row of equal character cards:

  [LV 07 — XP 240/400]=================
  |                                  |
  |         PLAYABLE FIELD       ! → |
  |                                  |
  |                     [2 MIRA       |
  |                      HP 62/90     |
  |                      READY]       |
  |                     [3 ADELA      |
  |                      HP 38/80     |
  |                      READY]       |
  [ACTIVE: SOL · HP 74/100]  [02:18 LEFT]

The active character gets one broad HP gauge below the battlefield. Reserve teammates occupy two narrow, vertically stacked swap paddles on the right. A swap exchanges the chosen paddle with the broad active gauge. Keep each character’s numeric shortcut attached to its identity. Show every character’s individual numeric HP and proportional gauge continuously.

XP is a quiet, thin top-edge track with level and progress. Remaining time sits in a substantial bottom-right instrument, readable at a glance without becoming a heading.

A shared 1.25-second cooldown draws the same shrinking hatch overlay across both eligible reserve paddles. Replace READY with the remaining tenths; use one shared “SWAP” label between them so the lockout reads as a team rule. Rejected taps give brief local feedback, never a screen shake. Automatic attacks need no attack button.

Danger uses at most three edge chevrons pointing toward nearby threats, with stronger weight for closer threats. Use shape and contrast as well as color. Keep enemy attack warnings visible in the field.

Desktop: WASD movement; 1/2/3 select fixed teammate identities. Landscape touch: left thumb movement zone and two 56-pixel-minimum swap targets at the right, inset from safe areas. All critical text sits clear of thumb zones. Avoid hover-dependent information.

Build with flat fills, borders and reusable gauges. Animate only the cooldown sweep and a brief active-selection snap; respect reduced motion. Ship this direction directly. Check time, all HP values, XP and swap readiness against a busy battlefield at both target sizes.

B. Button hit area only

Keep the visible button 36 pixels high. Add a transparent, absolutely positioned hit region extending four pixels above and below, producing a 44-pixel target without affecting layout. Ensure the invisible target is also at least 44 pixels wide. Preserve the visible width, label, colors, focus behavior and action.

Verify unchanged element positions and screenshots; test activation at both added edges, keyboard activation and focus. Confirm the enlarged region is not clipped and does not overlap neighboring controls. No other screen changes.
