DESIGN.md

# Ledger design

`domain.py` validates event shapes and decimal syntax and converts money to integer
cents. No floating-point or context-limited decimal arithmetic is involved. Names
are validated but preserved exactly; amounts normalize by numeric cents, including
signed zero. Decimal strings have digits before the optional decimal point and
one or two digits after it; an optional leading sign is supported.

`repository.py` owns balances, last sequences, and immutable original receipts.
`service.py` enforces sequencing, idempotency and nonnegative balances and builds
public responses. A replay reads the receipt's original balance, not today's.

Each batch shallow-copies the three state dictionaries. Their values are integers
or immutable receipts, so staged changes cannot leak into committed state. Only
successful exhaustion of the single-pass input commits the staged state by one
reference replacement. Validation failures, conflicts, overdrafts and iterator
exceptions all discard the snapshot. Inputs are never modified. This trades
O(total stored state) copying per batch for simple, auditable atomicity.

This is an in-memory, synchronous API, not a concurrent or durable database.
A future durable backend would replace snapshot copying with a database
transaction covering balances, sequences and receipts, with a unique constraint
on (tenant, event_id) and serialization of each tenant's updates. Domain parsing
and public response behavior could remain unchanged; transaction orchestration
would need to move behind a repository transaction boundary.

"""Validation and exact money representation, independent of stored state."""
from dataclasses import dataclass
import re


_DECIMAL = re.compile(r'[+-]?[0-9]+(?:\.[0-9]{1,2})?\Z')


def amount(value):
    """Parse a plain decimal string into integer cents (without rounding)."""
    if not isinstance(value, str) or not _DECIMAL.fullmatch(value):
        raise ValueError('amount must be a plain decimal string with at most two places')
    negative = value.startswith('-')
    unsigned = value.lstrip('+-')
    whole, _, fraction = unsigned.partition('.')
    cents = int(whole) * 100 + int(fraction.ljust(2, '0'))
    return -cents if negative else cents


def format_money(cents):
    sign = '-' if cents < 0 else ''
    whole, fraction = divmod(abs(cents), 100)
    return f'{sign}{whole}.{fraction:02d}'


@dataclass(frozen=True)
class Event:
    tenant: str
    event_id: str
    seq: int
    cents: int

    @classmethod
    def parse(cls, raw):
        if not isinstance(raw, dict):
            raise ValueError('event must be a dictionary')
        tenant, event_id = raw.get('tenant'), raw.get('event_id')
        if any(not isinstance(value, str) or not value.strip()
               for value in (tenant, event_id)):
            raise ValueError('tenant and event_id must be nonblank strings')
        seq = raw.get('seq')
        if isinstance(seq, bool) or not isinstance(seq, int) or seq <= 0:
            raise ValueError('seq must be a positive integer')
        return cls(tenant, event_id, seq, amount(raw.get('amount')))

ledger/service.py

"""Batch orchestration and ledger transition rules."""
from .domain import Event, format_money
from .repository import MemoryState, Receipt


class Ledger:
    def __init__(self):
        self.state = MemoryState()

    def balance(self, tenant):
        return format_money(self.state.balances.get(tenant, 0))

    def apply_batch(self, events):
        staged = self.state.snapshot()
        result = []
        for raw in events:
            event = Event.parse(raw)
            key = (event.tenant, event.event_id)
            receipt = staged.receipts.get(key)
            applied = receipt is None
            if receipt is not None:
                if (receipt.seq, receipt.cents) != (event.seq, event.cents):
                    raise ValueError('idempotency key reused with different contents')
            else:
                if event.seq != staged.sequences.get(event.tenant, 0) + 1:
                    raise ValueError('new events must have consecutive sequence numbers')
                balance = staged.balances.get(event.tenant, 0) + event.cents
                if balance < 0:
                    raise ValueError('insufficient funds')
                receipt = Receipt(event.seq, event.cents, balance)
                staged.balances[event.tenant] = balance
                staged.sequences[event.tenant] = event.seq
                staged.receipts[key] = receipt
            result.append({'tenant': event.tenant, 'event_id': event.event_id,
                           'applied': applied, 'balance': format_money(receipt.balance)})
        # Commit only after successful exhaustion, including iterator finalization.
        self.state = staged
        return result

DESIGN.md

# Ledger design

The domain module validates event fields and converts monetary strings to
integer cents. Arithmetic uses integers, independent of floating-point precision
and the active decimal context. Tenant and event IDs are checked for blankness
but otherwise retained as supplied.

The repository owns current per-tenant sequence and balance, plus immutable
event records keyed by tenant and event ID. It looks up replays before checking
sequence continuity so old events can return their original post-event balances.
The service consumes the iterable once and assembles the public response.

Each batch starts with shallow copies of the repository's maps. Their values
are immutable, so staged writes cannot leak into committed state. Later events
in the same batch see earlier staged writes. The service replaces the committed
state only after iteration and response construction finish successfully. Any
exception propagates without publishing the draft. This is batch atomicity for
serial calls, not a guarantee of thread-safe concurrent writes.

Copying the maps costs time and memory proportional to retained state, even
for a small batch. If persistence becomes necessary, the repository can store
accounts and event records in a database with a unique tenant/event-ID key.
The service would replace copying and publishing with a transaction that
commits after iterator exhaustion; the validation and response shape could
remain unchanged. Concurrent writers would also need transactional protection
around the per-tenant sequence and balance checks.

"""Validation and exact money conversion at the ledger boundary."""

import re
from decimal import Decimal


_PLAIN_DECIMAL = re.compile(r'[+-]?(?:[0-9]+(?:\.[0-9]{0,2})?|\.[0-9]{1,2})')


def amount(value):
    """Normalize a plain decimal string to integer cents."""
    if not isinstance(value, str) or not _PLAIN_DECIMAL.fullmatch(value):
        raise ValueError('amount must be a plain decimal string with at most two decimal places')
    whole, _, fraction = value.partition('.')
    # Convert without Decimal arithmetic (which would use the ambient context)
    # or a direct string-to-int conversion (which can have a digit limit).
    return int(Decimal(whole + fraction.ljust(2, '0')))


def format_balance(cents):
    whole, fraction = divmod(cents, 100)
    return f'{Decimal(whole):f}.{fraction:02d}'


def validate_event(event):
    if not isinstance(event, dict):
        raise ValueError('event must be a dictionary')
    tenant = event.get('tenant')
    event_id = event.get('event_id')
    seq = event.get('seq')
    for name, value in (('tenant', tenant), ('event_id', event_id)):
        if not isinstance(value, str) or not value.strip():
            raise ValueError(f'{name} must be a nonblank string')
    if isinstance(seq, bool) or not isinstance(seq, int) or seq < 1:
        raise ValueError('seq must be a positive integer')
    return tenant, event_id, seq, amount(event.get('amount'))

ledger/repository.py

"""In-memory ledger state and its transaction-local updates."""

from typing import NamedTuple


class EventRecord(NamedTuple):
    seq: int
    cents: int
    balance: int


class MemoryState:
    def __init__(self):
        self._accounts = {}
        self._events = {}

    def copy(self):
        staged = MemoryState()
        staged._accounts = self._accounts.copy()
        staged._events = self._events.copy()
        return staged

    def balance(self, tenant):
        return self._accounts.get(tenant, (0, 0))[1]

    def apply(self, tenant, event_id, seq, cents):
        key = tenant, event_id
        record = self._events.get(key)
        if record is not None:
            if (seq, cents) != (record.seq, record.cents):
                raise ValueError('event ID was already used with a different sequence or amount')
            return False, record.balance

        last_seq, balance = self._accounts.get(tenant, (0, 0))
        if seq != last_seq + 1:
            raise ValueError('new events must have consecutive sequence numbers')
        balance += cents
        if balance < 0:
            raise ValueError('insufficient funds')

        self._accounts[tenant] = (seq, balance)
        self._events[key] = EventRecord(seq, cents, balance)
        return True, balance

from .repository import MemoryState


class Ledger:

        self._state = MemoryState()

# Education expenditure and income: descriptive investigation

## Questions and available evidence
The original questions ask (1) in what regions increased education spending
positively impacts per capita GDP and (2) what impact increased education
expenditure has on per capita GDP in developing countries. This file cannot
identify causal impacts or answer those questions literally.

The supplied `data.csv` has 12 indicator rows: six series for each of two
**group aggregates**, not individual countries. Its 41 annual columns span
1975–2015. The groups are Sub-Saharan Africa (`SSF`) and Lower middle income
(`LMC`). LMC is an income category, not a geographical region; these categories
can overlap and do not represent all developing countries.

The requested income series `NY.GNP.PCAP.KD` is **GNI per capita in constant
2015 US dollars**, not GDP per capita in 2010 dollars. The education series
`NY.ADJ.AEDU.GN.ZS` is **adjusted savings: education expenditure (% of GNI)**,
not education spending as a percentage of total government expenditure. The
metadata's introductory description uses the latter GDP and government-budget
concepts, inconsistent with the actual series codes and names. Its SSA code
also differs from the actual SSF code. We use the CSV identifiers and labels.
The metadata's phrase “saved for future education expenditures” should not be
read as evidence that this measures a stock of earmarked future savings;
the supplied series is an education-expenditure share in the adjusted-savings
framework. No external indicator documentation was retrieved.

Other available series concern exports growth, gross primary/secondary
enrollment, and labor-force participation. The last is not total labor-force
size, despite the introductory metadata wording. They are not used as controls
in this deliberately small bivariate analysis.

## Method and reproducibility
Run `python3 analyze.py data.csv > results.json` using Python's standard library.
The script reads its argument, selects the two exact series codes, pairs finite
numeric observations by year within each group, and sorts chronologically.
Blank, `..`, nonnumeric, and nonfinite values are excluded without imputation.
Only groups containing both series are included. Duplicate group/series rows
are rejected rather than arbitrarily selected.

For each group we report Pearson correlation and OLS with an intercept,
regressing income Y on education X. The slope is centered cross-product divided
by centered X sum of squares. We also apply the same calculations to annual
first differences, using only consecutive calendar years of complete pairs:
missing years are never bridged. Undefined correlations or slopes are JSON
null (fewer than two observations, constant X, or constant Y for correlation).
Differencing is a descriptive sensitivity analysis to common trends, not a
causal identification strategy. It relates contemporaneous changes and does
not model delayed education effects. No significance tests are claimed.

## Findings
Slopes are constant-2015 US dollars per capita per **one percentage-point**
education share, or dollars of annual income change per percentage-point annual
share change for differences. Values below are rounded; `results.json` retains
full computed precision.

Education has 41 finite annual observations in each group, but SSF income has
only five (2011–2015); LMC income has all 41. The apparent 1975–2015 coverage
therefore does not provide 41 usable income/education pairs for Africa.

Both groups show negative level associations. For LMC, the association of
annual changes is weakly positive and close to zero, unlike the negative level
association. For SSF, both are negative, but the change analysis has only four
pairs. Thus the only positive descriptive result is a very small correlation
of annual changes for the lower-middle-income aggregate; it is not evidence
that spending increases positively impact GDP. Neither observed regional
aggregate provides a positive level association, and these two groups cannot
rank regions worldwide.

## Interpretation, limitations, and provenance
These are observational aggregate time series. Reverse causation, omitted
variables, shared trends, serial dependence, spending measured relative to GNI,
changing group composition, and aggregation can all affect the estimates.
A share can change because its income denominator changes without an increase
in real education resources. The groups overlap and have different usable
periods, precluding a clean comparative effect interpretation. First differences
do not resolve confounding or simultaneity and may amplify measurement noise.
No intervention, instrument, comparison design, or individual-country panel is
present. Results support only the associations above, not causal effects,
country-level claims, or a definitive conclusion about developing countries.

"""Descriptive, contemporaneous education/income associations from WDI wide CSV."""
import csv
import json
import math
import re
import sys

SERIES = {"income": "NY.GNP.PCAP.KD", "education": "NY.ADJ.AEDU.GN.ZS"}


def numeric(value):
    try:
        result = float(value)
    except (TypeError, ValueError):
        return None
    return result if math.isfinite(result) else None


def summarize(pairs):
    n = len(pairs)
    result = {"n": n, "pearson_r": None, "ols_slope": None}
    if n < 2:
        return result
    xs, ys = zip(*pairs)
    mx, my = math.fsum(xs) / n, math.fsum(ys) / n
    dx, dy = [x - mx for x in xs], [y - my for y in ys]
    xx = math.fsum(x*x for x in dx)
    yy = math.fsum(y*y for y in dy)
    xy = math.fsum(x*y for x, y in zip(dx, dy))
    if xx:
        result['ols_slope'] = numeric(xy / xx)
    if xx and yy:
        result['pearson_r'] = numeric(xy / math.sqrt(xx) / math.sqrt(yy))
    return result


def analyze(path):
    groups = {}
    with open(path, newline='', encoding='utf-8-sig') as handle:
        reader = csv.DictReader(handle)
        years = []
        for field in reader.fieldnames or []:
            match = re.fullmatch(r'(\d{4})(?: \[YR\1\])?', field.strip())
            if match:
                years.append((int(match.group(1)), field))
        years.sort()
        for row in reader:
            code, series = row['Country Code'].strip(), row['Series Code'].strip()
            if not code or series not in SERIES.values():
                continue
            group = groups.setdefault(code, {'label': row['Country Group'], 'data': {}})
            if series in group['data']:
                raise ValueError('Duplicate group/series: ' + code + '/' + series)
            group['data'][series] = {year: numeric(row[field]) for year, field in years}
    output = {}
    for code, group in sorted(groups.items()):
        data = group['data']
        if not all(series in data for series in SERIES.values()):
            continue
        x, y = data[SERIES['education']], data[SERIES['income']]
        paired = [(year, x[year], y[year]) for year in sorted(x.keys() & y.keys())
                  if x[year] is not None and y[year] is not None]
        differences = [(b[1]-a[1], b[2]-a[2]) for a, b in zip(paired, paired[1:])
                       if b[0] == a[0]+1]
        output[code] = {'label': group['label'],
                        'level': summarize([(x, y) for _, x, y in paired]),
                        'difference': summarize(differences)}
    return {'series': SERIES, 'groups': output}


if __name__ == '__main__':
    if len(sys.argv) != 2:
        raise SystemExit('Usage: python3 analyze.py CSV_PATH')
    print(json.dumps(analyze(sys.argv[1]), allow_nan=False))

# Education expenditure and income in the supplied World Bank extract

## What the questions become with these data

The original questions ask where increased education spending **positively impacts per capita GDP**, and what its **impact on per capita GDP in developing countries** is. The extract can answer a narrower descriptive question: within each of two World Bank aggregates, how do an education expenditure share and real GNI per capita move together, in levels and in year-to-year changes? It cannot identify an impact on GDP.

- **Income (Y):** `NY.GNP.PCAP.KD`, GNI per capita in constant 2015 US dollars, not GDP per capita in 2010 dollars as the metadata overview suggests. GNI includes net primary income from abroad, unlike GDP.
- **Education (X):** `NY.ADJ.AEDU.GN.ZS`, “Adjusted savings: education expenditure,” measured in percent of GNI, not percent of total government expenditure. The adjusted-savings label is an accounting classification, not evidence of money set aside for future education as the metadata's series description suggests. An increase in this ratio is not necessarily an increase in the amount spent: the denominator can change too.
- **Groups:** the CSV labels Sub-Saharan Africa as **SSF**, whereas the metadata says **SSA**. Lower middle income (**LMC**) is an income classification, not a geographic region or a proxy for all developing countries. The groups are not necessarily disjoint. The CSV contains aggregate series, not individual country observations.
- **Coverage:** the CSV has columns for 1975–2015, but only five years of Sub-Saharan African GNI per capita. Both education series and the LMC income series cover all 41 years. Exports growth, gross primary and secondary enrollment, and labor force participation (a rate, not a headcount) are also present but not used as controls.

## Method and findings

Within each group, pair finite numeric values in the same calendar year and discard missing pairs without imputation. Report Pearson's correlation and the OLS slope with an intercept, regressing income on the education share. Repeat using same-year changes from the previous calendar year, only where both endpoints have valid pairs. Differencing reduces the influence of persistent levels and some trends that can dominate a levels comparison. It addresses short-run co-movement, not long-run or lagged relationships, and does not by itself remove confounding.

|---|---|---|---:|---:|---:|
| Sub-Saharan Africa (SSF) | Levels | 2011–2015 | 5 | −0.966 | −159.13 |
| Sub-Saharan Africa (SSF) | First differences | 2012–2015 | 4 | −0.456 | −80.48 |
| Lower middle income (LMC) | Levels | 1975–2015 | 41 | −0.481 | −635.07 |
| Lower middle income (LMC) | First differences | 1976–2015 | 40 | +0.079 | +11.06 |

Slopes are in constant 2015 US dollars of GNI per capita per percentage point of the education share. In first differences, the slope compares changes in those quantities: in LMC, a one-percentage-point larger annual change in the share is associated with an approximately $11 larger annual change in GNI per capita in the fitted line.

Neither aggregate shows a positive association in levels. The LMC association changes sign after differencing, but the positive correlation is close to zero. SSF remains negative after differencing, but four changes are too few to draw a reliable regional conclusion. The two groups are observed over very different periods, so the slope contrast cannot be attributed to region or income classification.

## What is warranted

No geographic region in this extract shows a positive association under either specification, and the weak positive association in LMC annual changes does not establish a positive impact in developing countries. Nor do the negative slopes establish harm. Economic shocks, reverse causality, a changing GNI denominator, differences in aggregate membership or composition, omitted variables and serial dependence can all complicate interpretation. These are contemporaneous, unadjusted descriptive estimates; there is no causal design, country-level evidence, or inference about delayed returns to education.

The supplied files come from Allen Institute for AI's [DiscoveryBench](https://github.com/allenai/discoverybench), revision `c31fcf011e070f021a5f5b906896d0821f6880e8`, path `discoverybench/real/test/worldbank_education_gdp`. """Describe the within-group association of two WDI series."""
import argparse
import csv
import json
import math
import re
from decimal import Decimal, InvalidOperation, localcontext
from itertools import pairwise

SERIES = {"income": "NY.GNP.PCAP.KD", "education": "NY.ADJ.AEDU.GN.ZS"}
YEAR = re.compile(r"(\d{4})(?:\s+\[YR\1\])?")


def number(cell):
    try:
        value = Decimal(cell or "")
    except InvalidOperation:
        return None
    return value if value.is_finite() else None


def json_number(value):
    result = float(value)
    return result if math.isfinite(result) else None


def summarize(pairs):
    n = len(pairs)
    stats = {"n": n, "pearson_r": None, "ols_slope": None}
    if n < 2:
        return stats

    x, y = zip(*pairs)
    # Center for the intercept fit. Shift first to remove common offsets
    # and to make a constant series yield exactly zero variance.
    x = [v - x[0] for v in x]
    y = [v - y[0] for v in y]
    mean_x, mean_y = sum(x) / n, sum(y) / n
    dx = [v - mean_x for v in x]
    dy = [v - mean_y for v in y]
    xx = sum(v * v for v in dx)
    yy = sum(v * v for v in dy)
    if xx:
        xy = sum(a * b for a, b in zip(dx, dy))
        stats["ols_slope"] = json_number(xy / xx)
        if yy:
            r = xy / (xx * yy).sqrt()
            stats["pearson_r"] = json_number(max(-1, min(1, r)))
    return stats


def analyze(path):
    rows = {}
    with open(path, newline="", encoding="utf-8-sig") as stream:
        reader = csv.DictReader(stream)
        years = sorted(
            (int(match[1]), header)
            for header in reader.fieldnames or []
            if (match := YEAR.fullmatch(header.strip()))
        )
        for row in reader:
            series = row["Series Code"].strip()
            if series in SERIES.values():
                code = row["Country Code"].strip()
                rows.setdefault(code, {})[series] = row

    groups = {}
    for code, by_series in sorted(rows.items()):
        if len(by_series) != len(SERIES):
            continue
        education = by_series[SERIES["education"]]
        income = by_series[SERIES["income"]]
        paired = []
        for year, header in years:
            x, y = number(education[header]), number(income[header])
            if x is not None and y is not None:
                paired.append((year, x, y))

        with localcontext() as ctx:
            ctx.prec = 50
            groups[code] = {
                "label": education["Country Group"],
                "level": summarize([(x, y) for _, x, y in paired]),
                "difference": summarize([
                    (x1 - x0, y1 - y0)
                    for (t0, x0, y0), (t1, x1, y1) in pairwise(paired)
                    if t1 == t0 + 1
                ]),
            }
    return {"series": SERIES, "groups": groups}


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("csv_path")
    args = parser.parse_args()
    print(json.dumps(analyze(args.csv_path), indent=2, allow_nan=False))
