# 보건의료 통계 출처와 접근법

2026-07 기준 직접 확인한 경로. 링크가 죽거나 사이트 구조가 바뀌면 이 문서를 고친다.

## 한국 — 탐색 순서

1. **국가지표체계 지표누리** (index.go.kr) — 국가 공식 지표. 통계명·작성기관·공표주기·지표 정의가 한 화면에 있다. **여기부터 본다.**
2. **KOSIS** (kosis.kr) — 국가승인통계. 대외 인용에 통계표 번호가 필요할 때
3. **소관 기관 직접** — 심평원 보건의료빅데이터개방시스템, 건보공단 통계연보, 각 부처 통계자료실
4. **지자체 열린데이터** — 지역 비교가 필요할 때
5. **공공데이터포털** (data.go.kr) — OpenAPI. 단 통계가 아니라 **행정 정보**인 경우가 많다

### 함정

- **요청자가 "통계청 자료"라고 해도 통계청이 만들지 않는 지표가 많다.** 통계청/국가데이터처는 지표를 관리할 뿐 생산기관이 따로인 경우가 흔하다. 지표누리 화면의 "출처" 줄을 확인한다
- **지표누리 본문은 JS 렌더링이라 자동 수집이 안 된다.** iframe 직접 주소에 표 HTML이 그대로 있다:
  ```
  https://www.index.go.kr/unity/potal/eNara/sub/showStblGams3.do?stts_cd=<지표코드>01&idx_cd=<지표코드>&freq=Y&period=<시작>:<끝>
  ```
  본문 페이지에서 iframe src를 읽어 확인한다
- **KOSIS statHtml 직접 접근은 SSO 리다이렉트로 막힌다.** 브라우저 필요
- **공공데이터포털의 "OpenAPI"와 "파일데이터"는 다르다.** 파일데이터는 XLS 다운로드다

## 국제 — 두 층

### 1층: 국제기구 (순위·평균)

**OECD SDMX API — 인증 불필요, 즉시 사용 가능**

```bash
# 데이터플로 목록
curl -H "Accept: application/vnd.sdmx.structure+json;version=1.0" \
  "https://sdmx.oecd.org/public/rest/dataflow/OECD.ELS.HD/all/latest"

# 데이터 (CSV)
curl -H "Accept: application/vnd.sdmx.data+csv;version=1.0.0" \
  "https://sdmx.oecd.org/public/rest/data/OECD.ELS.HD,<DATAFLOW_ID>,1.0/all?startPeriod=2019"
```

CSV를 받은 뒤 반드시 확인할 것:
- **연도별 보고국 수** — 최신 연도는 보고국이 급감한다. 비교 가능한 마지막 연도를 찾는다
- **우리나라가 그 연도에 있는지** — 특정 시점부터 제출을 중단한 나라가 있다
- **UNIT_MEASURE와 MODE 차원** — 같은 지표에 여러 단위·모드가 섞여 있다. 하나로 고정하지 않으면 중복 행이 나온다

OECD 웹페이지(oecd.org)는 자동 수집이 403으로 막힌다. API를 쓴다.

**WHO GHO OData API — 결과 지표(사망률)는 여기가 1층**

```bash
# 지표 코드 찾기
curl -G "https://ghoapi.azureedge.net/api/Indicator" \
  --data-urlencode "\$filter=contains(IndicatorName,'mortality')"

# 데이터 — 필터는 국가가 아니라 연도로 자른다
curl -G "https://ghoapi.azureedge.net/api/<CODE>" \
  --data-urlencode '$filter=TimeDim ge 2019 and TimeDim le 2021'
```

- 긴 `or` 필터는 API 노드 제한으로 400 응답이 날 수 있다. 국가를 길게 나열하지 말고 연도로 자른 뒤 로컬에서 거른다
- `Dim1`에 성별 차원이 섞여 있다. `SEX_BTSX` 또는 `None`만 남긴다
- `SpatialDim`에 지역 집계 코드가 섞인다. 3글자 ISO만 남긴다
- 자주 쓰는 코드: `MDG_0000000026` 모성사망비(1985~), `WHOSIS_000003` 신생아사망률(1951~)
- **모성사망비는 MMEIG 모델 추정치라 각국 공식 통계와 다를 수 있다.** 자국 수치는 자국 통계기관 값을 우선하고, 두 지표 모두 자국 공식 통계와 정의·값을 대조한다

**국제기구 성명·가이드라인은 원문 PDF를 연다.** 통용되는 요약이 원문과 다른 경우가 많다. 문서번호와 발행일까지 적는다.

**기타 1층**: Euro-Peristat (유럽 주산기), Eurostat

### 2층: 각국 통계기관 (최신 수준·추세)

1층이 낡았을 때 반드시 내려간다. 보건 분야 검증된 출처:

| 국가 | 기관 | 발표 시기 |
|---|---|---|
| 핀란드 | THL 주산기통계 | 11월경 |
| 스웨덴 | Socialstyrelsen | 12월경 |
| 네덜란드 | Perined | 봄 |
| 노르웨이 | 의학적출생등록부(MBRN/FHI) | 웹 무료 조회 |
| 일본 | 후생노동성 「의료시설(정태·동태)조사」 | **3년 주기** |

검색어는 **현지어**로 넣는다. 영어로는 국가 통계기관 원본이 잘 안 나온다.

2층 수치는 **정의가 국제 조화 기준과 다를 수 있다.** 순위를 매기지 않고 수준·방향에만 쓴다.

**국제기구 미보고국이 곧 자료 없음은 아니다.** 미국·일본처럼 특정 지표를 OECD에 제출하지 않는 나라도 자국 조사에는 있다. 일본 후생노동성 조사는 PDF 표에 시설종별 건수만 주므로 **전국 비율은 합산해서 직접 계산**해야 한다 (`pdftotext -layout`로 표 파싱). 조사 설계가 다르면(예: 특정 월만 집계) 수준이 아닌 **추세 비교**로 쓴다.

**비교 대상국 고르기 — 반박 가능성으로 고른다.** 성적이 가장 좋은 나라는 "제도가 다르잖아"로 반박당한다. 인구구조·의료전달체계가 우리와 유사한데 지표가 다른 나라를 **함께** 넣는다. 전자는 도달 가능한 최선을, 후자는 우리 조건에서의 가능성을 보여준다.

## 국제 표준 분류를 먼저 찾는다

"우리나라엔 그 지표가 없다"로 끝내기 전에, **국제 표준 분류 체계에 그 지표가 들어 있는지** 확인한다.

예: 제왕절개 분야의 WHO Robson 10군 분류 — 5군이 "제왕절개 기왕력 산모"이고, VBAC 관련 지표(시도율·성공률)는 이 군의 분만 방식에서 계산된다. 별도 통계를 만드는 게 아니라 분류 체계를 도입하면 따라오는 지표다.

이 발견은 리포트의 정책 제언으로 직결된다.

## 학술 문헌

- 국내: KCI, KoreaMed Synapse, DBpia
- 국제: PubMed/PMC
- **PMC는 WebFetch로 본문이 잘 읽힌다.** 정책 효과 분석은 여기서 나온다
- 스캔 PDF는 텍스트 레이어가 없어 읽히지 않는다. 이 경우 미확인으로 남기고 표시한다

**논문 수치를 쓸 때 모집단을 반드시 확인한다.** 전국 통계와 특정 종별·기관 통계를 섞으면 리포트가 무너진다. 논문 값이 전국 값과 크게 다르면 그게 오류가 아니라 모집단 차이일 가능성이 높다.
